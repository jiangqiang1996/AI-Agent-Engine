# GitHub 趋势榜文章格式模板

本文件是 `github-trending-article` 技能的参考样式真源。技能执行时直接读取本文件获取文章格式，无需访问外部博客网站。

## 文章结构

文章按以下结构组织，所有内容使用中文（仓库地址、仓库名、编程语言名等保留原文）：

1. 标题（含日期括号）
2. 趋势总览段落
3. 各仓库条目（序号标题 + 信息表格 + 中文介绍 + 活跃程度）
4. 不包含抓取来源、抓取时间等元信息描述

## 标题格式

```
# 🔥 GitHub 今日趋势仓库 TOP 10（YYYY-MM-DD）
```

日期为抓取当天的日期，与文件名中的日期保持一致。

## 趋势总览

标题下方紧跟趋势总览段落：

```
## 趋势总览

今日为您呈现 GitHub 上最受关注的 **10 个热门项目**。
```

## 仓库条目格式

每个仓库按以下格式呈现，序号使用带圈数字 emoji（1️⃣ 2️⃣ 3️⃣ 4️⃣ 5️⃣ 6️⃣ 7️⃣ 8️⃣ 9️⃣ 🔟）：

```
## 1️⃣ TOP 1：owner/repo

| 项目 | 信息 |
|------|------|
| **地址** | https://github.com/owner/repo |
| **⭐ 星标** | 3,929 |
| **🍴 派生** | 389 |
| **🔤 语言** | HTML |
| **📅 创建** | 2026-08-21（5天前） |

**📖 中文介绍：** 开源的 ThreeUI 社区目录，提供实时交互组件与完整的社区源码。

**📊 活跃程度：** 🔥🔥🔥🔥🔥 近7天新建即斩获近4000星，爆火

---
```

### 字段说明

| 字段 | 说明 |
|------|------|
| 地址 | 仓库完整 URL |
| ⭐ 星标 | 星标数，千分位逗号分隔 |
| 🍴 派生 | Fork 数，千分位逗号分隔 |
| 🔤 语言 | 主要编程语言 |
| 📅 创建 | 创建日期 + 括号内距今天数 |

### 中文介绍

将仓库英文描述翻译为中文，专有名词（如 MCP、TUI、ReAct、Codex）可保留英文。

### 活跃程度评级

根据近7天新增星标数评级，格式为 `🔥 等级 描述`：

| 等级 | 火苗数 | 条件 |
|------|--------|------|
| 爆火 | 🔥🔥🔥🔥🔥 | 近7天新增超1000星，或派生数超星标数 |
| 很活跃 | 🔥🔥🔥🔥 | 近7天新增超500星 |
| 较活跃 | 🔥🔥🔥 | 近7天新增超200星 |
| 一般 | 🔥🔥 | 其他 |
