# 运行时独立性规范

## 运行时独立性

- AE 插件的运行时实现必须独立于源码仓库布局，支持仅依赖桥接文件和 `dist` 目录完成加载与执行。
- 任何运行时代码只要涉及插件根目录解析、运行时资产定位、默认配置加载或内置资源发现，都不得把 `dist` 与桥接文件以外的仓库文件当作必需前提。
- 特别是不得把 `opencode.json` 作为插件根目录或运行时资产定位的硬依赖；如需兼容读取，只能作为可选兜底，不能影响脱离源码仓库后的可运行性。
- 新增或修改运行时相关代码时，必须优先基于实际分发结构推断路径，而不是基于源码目录、开发环境文件或仓库根标记做假设。
- 涉及运行时定位、加载或资源发现的改动，必须补充“仅桥接文件 + dist”场景的测试，防止编码阶段重新引入对源码文件的隐式依赖。

## 下游项目 AGENTS.md 边界

- 插件运行时不得把下游项目的 `AGENTS.md` 当作必需输入或结构化配置来源。
- 如需读取下游项目的 `AGENTS.md`，只能作为可选项目上下文；当文件缺失、格式未知、内容不相关或没有明确声明时，必须降级处理，不得假设存在固定字段、固定章节或固定规范语义。

## src 运行时封闭边界

- `src/` 是打包后插件能力真源；`src` 内的运行时代码、提示词、命令、代理和规则不得依赖当前项目 `.opencode/`、当前项目 `AGENTS.md`、本机 opencode 全局配置，或本机环境中的其他技能与配置。
- 除明确生成或使用 `docs/ae/` 下的插件工作流产物外，`src` 面向插件用户的能力不得引用或要求读取仓库其他目录文件。
- 如某项能力必须管理 opencode 项目配置，必须由用户明确触发为专项功能，并在代码、提示词或工具描述中标明这是配置管理行为，而不是插件运行时的默认依赖。
