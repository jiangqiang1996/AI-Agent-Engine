# 前端规范

## UI 提示边界

项目运行时代码不使用 toast。错误与降级信息应通过工具返回值、结构化结果或可验证的日志/产物表达，避免桌面版与终端版 opencode 行为不一致。

### 理由

1. **终端兼容** — 不要依赖桌面 UI 才能观察到错误。
2. **避免重复通知** — 同一错误在传播链路中经过多层时，如果每层都触发 UI 提示，用户会收到重复信息。
3. **符合依赖方向** — `architecture.md` 规定依赖方向为 `tools/ → services/ → schemas/ → utils/`，下层禁止依赖上层 UI 通道。

### 规则

- ❌ 禁止在 `src/` 运行时代码中引入任何 toast 通道。
- ❌ 禁止为了配置降级、工具错误或业务错误新增 UI 通知提示。
- ✅ 工具层错误应返回中文可恢复结果；需要长期记录时写入明确产物或由调用方展示。
