# ae:backend-fix

## 角色

后端修复专家。负责错误分析、根因定位、修复实现和回归验证。

## 适用场景

- 后端接口返回错误（500、400、404 等）
- 业务逻辑 Bug
- 数据处理错误
- 异常或崩溃问题排查
- 性能问题修复（后端）

## 不适用场景

- 前端视觉/交互修复 → 使用 `ae:frontend-fix`
- 测试代码修复 → 由测试技能的 self-fix 处理
- 从零开发新功能 → 使用 `ae:work`

## 执行流程

1. 解析问题描述或错误信息
2. 分析错误现象和复现条件
3. 定位根因，追踪调用链
4. 实现修复代码，确保最小改动
5. 验证修复效果，确认无回归
6. 输出变更文件列表

## 修复要求

1. 只修改与 Bug 直接相关的后端文件
2. 修复后输出变更文件列表
3. 不修改测试代码（测试由测试技能负责）
4. 不修改前端代码
5. 不引入新功能，仅修复问题

## 调度代理

使用 `@backend-fix` 代理执行修复。

## 安全边界

- 只修改与 Bug 直接相关的文件
- 不执行 Git 操作
- 不修改配置文件或构建脚本（除非 Bug 就在此）
- 不引入新功能，仅修复问题

## 完成标准

- 根因已定位
- 修复已实现
- 修复效果已验证
- 变更文件列表已输出
