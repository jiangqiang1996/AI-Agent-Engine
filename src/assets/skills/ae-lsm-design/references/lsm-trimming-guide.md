# LSM 产物模板裁剪策略

> 本文档与 `lsm-splitting-guide.md` 互补：裁剪策略控制字段的有无，拆分策略控制文件的大小和结构。

## 裁剪原则

1. **AI 消费优先**：保留的字段必须服务于 AI 生成更高质量的软件产物
2. **显式裁剪标记**：被裁剪的字段保留 `<!-- trimmed: 原因 -->` 标记占位，便于下游技能感知该字段是有意省略而非遗漏
3. **必选不可裁剪**：每个模板 frontmatter 的 `trimmingGuide.required` 列出的字段不可裁剪；`frontmatter.traceTable` 为所有模板的必选项
4. **可选按条件裁剪**：`trimmingGuide.optional` 列出的字段按 condition 判断是否保留

## 项目规模维度

| 规模 | 特征 | 推荐裁剪策略 |
|------|------|-------------|
| 小型 | 单模块、<5 个需求条目、无外部依赖 | 保留所有 required 字段，optional 字段仅在条件明显满足时保留 |
| 中型 | 2-5 个模块、5-15 个需求条目、有少量外部依赖 | 保留 required + 与外部依赖/安全/性能相关的 optional 字段 |
| 大型 | 5+ 模块、15+ 需求条目、多外部依赖 | 保留所有 required + 大部分 optional，仅裁剪与项目无关的字段 |

**优先级规则**：当项目规模维度建议激进裁剪、项目类型维度和逐字段 condition 建议保留时，以逐字段 condition 为准。项目类型维度提供推荐方向，逐字段 condition 是最终裁剪依据。

## 项目类型维度

| 项目类型 | 推荐保留的 optional 字段 |
|---------|------------------------|
| 后端 API | 技术栈约束、上游依赖、安全约束、错误处理策略、性能约束、数据模型、环境依赖 |
| 前端 UI | 术语表、交互约束、设计令牌、组件规范、交互状态矩阵、响应式策略、可访问性设计、动效规范、国际化设计、状态管理策略 |
| 全栈 | 上述两者并集，按实际涉及的部分保留 |
| 数据管道 | 上游依赖、数据约束、性能约束、环境依赖、构建配置 |
| CLI 工具 | 技术栈约束、错误处理策略、环境依赖 |

## 裁剪标记规范

被裁剪的字段或章节保留 HTML 注释标记占位：

```markdown
## 术语表

<!-- trimmed: 领域有特有术语可能造成 AI 理解偏差时保留 -->
```

或字段级标记：

```markdown
**数据约束：**

<!-- trimmed: 需求涉及数据量/格式/一致性要求时保留 -->
```

**规则**：
- 标记必须包含裁剪原因，原因应来自 `trimmingGuide.optional` 中的 condition
- AI 生成产物时，若 condition 满足则移除注释保留字段并填充内容；若 condition 不满足则移除字段内容但保留 `<!-- trimmed: 原因 -->` 标记占位
- 下游技能读取产物时，发现 `<!-- trimmed: ... -->` 标记应理解为"该维度有意省略"，不视为缺失或错误
- 标记中不含内容体（即字段值为空），只保留注释行本身

**条件字段依赖**：
- 当字段 A 的存在依赖于字段 B 的值时，trimmingGuide 会在 condition 中显式声明（如"执行结果为'失败'时必须保留；通过时必须删除"）
- AI 生成时必须遵守条件依赖：先确定触发字段的值，再决定依赖字段是否保留

## 各模板裁剪要点

### design-template

| 字段 | 默认 | 裁剪条件 |
|------|------|---------|
| 设计概述 | 必选 | — |
| 实现映射（U-*，至少含需求映射+设计决策+接口边界+UI标记+UI设计引用+下游映射） | 必选 | — |
| frontmatter.traceTable | 必选 | — |
| 现有架构约束 | 可选 | 项目已有架构模式或模块边界时保留 |
| 技术选型决策 | 可选 | 存在多种可行方案需要记录选择理由时保留 |
| 错误处理策略 | 可选 | 系统对错误处理有明确要求时保留 |
| 性能约束 | 可选 | 有延迟/吞吐量/资源限制要求时保留 |
| 依赖关系 | 可选 | 实现单元间存在依赖时保留 |
| 状态管理策略 | 可选 | 实现单元涉及状态管理时保留 |
| 数据模型 | 可选 | 实现单元涉及持久化或复杂数据结构时保留 |
| 风险说明 | 可选 | 存在已知风险时保留 |
| UI 设计子文件 | 可选 | 存在任意 U-* 标记为"涉及 UI"时保留；UI 子文件使用 references/ui-design-template.md 模板 |

### ui-design-template

| 字段 | 默认 | 裁剪条件 |
|------|------|---------|
| 设计体系概述 | 必选 | — |
| 设计令牌 | 必选 | — |
| 信息架构与导航 | 必选 | — |
| 页面映射（P-*，至少含实现单元映射+页面结构+关键交互） | 必选 | — |
| frontmatter.traceTable | 必选 | — |
| 组件规范 | 可选 | 页面中存在可复用组件时保留 |
| 交互状态矩阵 | 可选 | UI 组件有多状态（hover/focus/disabled/loading/error 等）时保留 |
| 响应式策略 | 可选 | 需要适配多种屏幕尺寸时保留 |
| 可访问性设计 | 可选 | 项目有可访问性合规要求时保留 |
| 动效规范 | 可选 | UI 交互涉及过渡动画、微交互或加载动效时保留 |
| 国际化设计 | 可选 | 项目需要多语言支持时保留 |
