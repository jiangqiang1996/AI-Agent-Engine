# ae:course-auto-player

> **chrome-devtools MCP 门禁**：执行任何 `chrome-devtools_*` 工具前，必须先通过 `ae:chrome-devtools` 完成 MCP 动态注册；MCP 注册不能替代门禁检查，未注册或未连接就绪时不得执行任何 chrome-devtools 工具，连接失败时记录"无法验证"并停止。

## 角色

在线课程自动完成器，自动完成在线学习网站的所有课程：连接浏览器、打开课程列表页面、按顺序遍历每节课，根据课程类型自动执行对应操作（文档阅读、视频播放、外链访问、考试智能答题），直至所有课程完成。

## 适用场景

- 用户提供一个课程列表页面 URL，希望自动完成所有课程
- 课程列表包含文档、考试、视频、外链等类型，需要自动化逐个处理
- 用户说"帮我刷课"、"自动完成课程"、"播放课程列表"等

## 不适用场景

- 用户只想打开单个页面浏览，不需要自动化遍历
- 课程网站需要人机验证（如滑块验证码）且无法自动通过
- 用户未提供课程列表页面 URL

## 核心设计原则

- **ae-timer + nextStep 防上下文丢失**：所有 `ae-timer` 调用必须传入 `nextStep` 参数，描述等待结束后应执行的操作。工具返回时原样携带，确保长时间等待后 LLM 无需回溯上下文即可继续。
- **视频 5 分钟分片轮询**：视频播放不使用一次长等待，而是每 5 分钟调用一次 `ae-timer`，返回后检查播放状态，再决定继续等待或关闭。这样即使视频被暂停、弹窗阻断或播放异常，也能及时发现并处理。
- **最小化 LLM 交互**：每种课程类型在等待期间 LLM 挂起不消耗 token，只在状态检查和决策点才恢复推理。
- **禁止中途询问是否继续**：除非遇到需要登录的页面或人机验证等必须用户介入的场景，否则不得在课程之间、视频之间或考试之间询问用户是否继续执行；所有课程必须自动顺序处理直到列表遍历完毕。

## 辅助脚本

所有辅助脚本通过 `chrome-devtools_evaluate_script` 执行。脚本中的选择器和文本模式可能需要根据目标网站微调，LLM 应在首次执行时根据页面快照调整配置，后续课程复用调整后的版本。

详见 [references/scripts.md](references/scripts.md)，包含：
- **检查视频状态**：获取 video 元素播放状态
- **提取课程列表**：从页面提取结构化课程数据（选择器和文本模式均可配置）
- **通用点击辅助脚本**：多级降级点击（native click → 鼠标事件序列 → 父元素点击）
- **导航验证脚本**：对比点击前后页面状态判断导航是否生效

## 输入处理

用户通过命令传入参数，格式为：

```
/ae-course-auto-player [browser] <课程列表页面URL>
```

参数解析规则（三级策略）：
1. 显式命名：`key=value`、`key:value`、`--key=value` 直接绑定，优先级最高
2. 值特征推断：按值的模式自动匹配参数类型（仅在参数意图上下文中生效）

   | 值模式 | 推断为 |
   |--------|--------|
   | http:// 或 https:// 开头 | url |
   | Chrome / Edge / Brave / Vivaldi | browser |

3. 顺序兜底：`browser → url`

**内部调用约定**：当本技能被其他技能自动调用时，所有参数必须使用显式命名格式（如 `url=https://example.com browser=Edge`），不依赖值特征推断。

- URL 为必填参数，必须是可访问的课程列表页面地址
- 如果用户未提供 URL，必须先询问，不得自行假设
- 如果用户提供的浏览器类型不在支持列表中，提示用户选择支持的类型

## 工作流程

### 前置：浏览器连接

使用 `ae:chrome-devtools` 技能完成浏览器 MCP 动态注册并确认连接就绪，传入 `browser` 参数（取自用户输入，默认 `Chrome`）。

### 第一步：打开课程列表页面

1. 调用 `chrome-devtools_list_pages` 列出当前标签页。
2. 检查是否已有标签页打开了目标 URL（精确匹配或相同路径匹配）。
   - 如果已存在，选择该标签页并刷新。
   - 如果不存在，调用 `chrome-devtools_new_page` 打开目标 URL。
3. 等待页面加载完成（等待 3 秒或调用 `chrome-devtools_wait_for` 等待页面关键文本出现）。
4. 执行**提取课程列表**辅助脚本，获取课程项结构化数据。
   - 如果返回 `total=0` 或课程名称不正确：调用 `chrome-devtools_take_snapshot` 获取页面结构，根据快照调整脚本中的选择器和文本模式配置，重新执行。
   - 配置调整后记录到上下文中，后续课程遍历复用该配置。
5. 如果返回的 `courses` 中有 `type=unknown` 的课程，调用 `chrome-devtools_take_snapshot` 获取页面结构，根据快照中对应课程的类型标签文本手动补充类型判断。
6. 将提取到的课程列表保存到上下文中，作为后续遍历的依据。

#### 课程类型识别规则

从列表页面的类型标签或操作按钮文本推断课程类型。以下为常见关键词示例，LLM 应根据目标网站实际文案调整 `typeKeywords` 和 `statusKeywords` 配置：

**类型推断示例**（对应脚本中 `typeKeywords` 配置）：

| 关键词示例 | 推断类型 | 说明 |
|------------|----------|------|
| "课程"/"course"/"lesson" | `course` | 内部课程，进入后可能是视频、文档或考试，需二次判断 |
| "考试"/"exam"/"quiz"/"test" | `exam` | 考试类课程 |
| "URL"/"外链"/"链接"/"external"/"link" | `url` | 外链类课程 |

**状态推断示例**（对应脚本中 `statusKeywords` 配置）：

| 按钮文本关键词示例 | 状态 | 说明 |
|---------------------|------|------|
| "开始"/"start"/"begin" | `not_started` | 未开始，需要处理 |
| "继续"/"continue"/"resume" | `in_progress` | 进行中，需要继续处理 |
| "重新"/"re-"/"redo"/"retry" | `completed` | 已完成，可跳过或重新学习 |

**已完成的课程（`status=completed`）默认跳过**，除非用户明确要求重新学习所有课程。

### 第二步：遍历课程列表

按顺序遍历每节课（跳过 `status=completed` 的课程，除非用户要求重新学习），根据类型执行对应操作：

#### 文档类课程

1. 按照点击操作降级策略，在课程列表页面点击该节课进入课程详情。
2. 等待文档页面加载完成，调用 `chrome-devtools_take_snapshot` 确认页面内容已变化。
3. 调用 `ae-timer duration=5 label="等待文档阅读" nextStep="文档阅读等待结束，请关闭当前文档标签页，返回课程列表页面，继续处理下一节课"`。
4. ae-timer 返回后，按 nextStep 指示关闭文档标签页（或导航回课程列表页面），返回课程列表页面。

#### 考试类课程

详见 [references/exam-strategy.md](references/exam-strategy.md)，包含六个阶段：获取题目 → 作答策略 → 填写提交 → 完成状态检查 → 采集历史批改记录 → 重新考试。

#### 视频类课程

1. 按照点击操作降级策略，在课程列表页面点击该节课进入视频详情。
2. 等待视频页面加载完成，执行视频状态检查脚本获取视频信息。
3. 检查视频状态是否正常：
   - 如果返回 `error:'no video element'`：页面上无视频元素，可能页面尚未加载完成，等待 3 秒后重试一次。如果仍然无视频元素，跳过该课程并在汇报中标注。
   - 如果 `paused=true`：点击播放按钮启动播放，尝试设置 1.5 倍速（倍速不超过 1.5x）。
   - 如果 `paused=false`：视频已在播放，尝试设置 1.5 倍速。
4. 再次执行视频状态检查脚本，确认 `paused=false`，记录 `duration`、`currentTime`、`playbackRate`。
5. 进入 5 分钟分片轮询循环：
   - 构造 nextStep 内容，包含：当前课程名、视频总时长、当前播放进度、播放倍速、课程列表中剩余课程信息。
   - 调用 `ae-timer duration=300 label="等待视频播放: <课程名> (<当前进度>/<总时长>s)" nextStep="<包含播放状态和后续指令的完整描述>"`。
   - ae-timer 返回后，执行视频状态检查脚本：
     - 如果 `ended=true` 或 `currentTime >= duration`：视频已播完，退出轮询。
     - 如果 `paused=true` 且非自然结束：视频被暂停或有弹窗，点击播放/关闭弹窗恢复播放，然后重新调用 ae-timer 继续 5 分钟等待。
     - 如果仍在播放：重新调用 ae-timer 继续 5 分钟等待，更新 nextStep 中的播放进度。
     - 如果返回 `error`：视频元素丢失，跳过该课程并标注。
6. 视频播完后，关闭视频标签页，返回课程列表页面。

##### 视频轮询 nextStep 模板

每次调用 ae-timer 时，nextStep 应包含以下信息（根据实际情况填写）：

```
视频播放等待结束。当前课程：<课程名>。请执行视频状态检查脚本，根据结果：
1. 如果视频已播完（ended=true 或 currentTime>=duration）：关闭当前视频标签页，返回课程列表页面，继续下一节课<下一节课名>。
2. 如果视频被暂停（paused=true）：点击播放按钮恢复播放，然后重新调用 ae-timer duration=300 继续等待。
3. 如果视频仍在播放：重新调用 ae-timer duration=300 继续等待。
```

#### 外链类课程

1. 按照点击操作降级策略，在课程列表页面点击该节课进入外链详情。
2. 等待外链页面加载完成，调用 `chrome-devtools_take_snapshot` 获取页面结构。
3. 判断外链内容是否为另一个课程列表页面：
   - 如果页面结构与课程列表页面类似（包含多节课、有课程类型标识），则递归执行本技能的"第二步：遍历课程列表"流程处理该页面上的所有课程。
   - 如果不是课程列表页面，调用 `ae-timer duration=3 label="等待外链页面" nextStep="外链等待结束，请关闭当前外链标签页，返回课程列表页面，继续处理下一节课"`。
4. 关闭外链标签页（或导航回课程列表页面），返回原课程列表页面。

### 第三步：完成汇报

所有课程处理完毕后，输出完成摘要：

- 已完成课程数量和列表（按类型分组）。
- 考试类课程的详细信息：
  - 考试名称、考试成绩、是否通过。
  - 重考次数（如重考过）。
  - 每次考试的置信度分布（高/中/低各多少题）。
  - 未能获取错题的考试（如有）。
- 跳过或失败的课程及原因。
- 已关闭的临时标签页数量。

## 标签页管理规则

- 课程列表页面始终保持在一个固定标签页中，不关闭。
- **SPA 网站**：许多课程网站是 Vue/React 等 SPA，点击课程后不会打开新标签页，而是在当前页面通过 hash 路由切换视图。此时"关闭标签页返回课程列表"应改为"导航回课程列表 URL"（使用 `chrome-devtools_navigate_page`）。
- 在多标签页网站（点击课程会打开新标签页）中，每节课在单独的新标签页中打开，处理完毕后立即关闭该标签页。
- 每次处理完一节课后，确认回到课程列表页面（通过导航或选择标签页）再继续下一节课。
- 如果标签页数量超过 10 个，暂停并关闭所有非课程列表标签页后再继续。

## 安全边界

- 本技能仅处理用户明确指定的课程 URL，不自动发现或访问未授权的课程。
- 考试答题由 LLM 直接推理作答，不使用多代理并行分析或搜索验证；重考时利用历史批改记录中的正确答案和排除法提升正确率。
- 视频播放倍速不超过 1.5 倍，遵守课程网站规则。
- 遇到需要登录的页面时，提示用户手动登录后继续，不自动输入凭据。
- 遇到人机验证（验证码、滑块等）时，提示用户手动完成后继续。
- 不修改课程网站的账户设置或个人信息。
- 无法获取错题详情时必须如实告知用户，不得伪造或跳过。

## 验证方式

- 确认所有课程列表中的课程都已处理（完成或跳过并记录原因）。
- 确认所有临时标签页已关闭，仅保留课程列表标签页。
- 确认汇报中的课程数量与列表中识别到的数量一致。
