# 浏览器目标选择契约

本文件定义 `ae:agent-browser` 在环境就绪后如何选择浏览器目标。任何消费方需要实际浏览器操作时，应引用本契约，而不是复制独立连接流程。

## 默认顺序

1. 展示可发现的现有浏览器或已有 agent-browser session 候选摘要。
2. 说明连接已有浏览器的 CDP 暴露范围和登录态风险。
3. 询问用户确认目标；即使只有一个候选，也必须确认。
4. 用户确认后连接目标并先做只读观察。
5. 接管失败或用户不确认时，询问打开新受控浏览器，或指导用户按 remote debugging 参数重启已有浏览器后连接。

## 可选目标

- 用户提供的 CDP 端口或 URL。
- 自动发现的可连接浏览器。
- 已有 agent-browser session。
- 新打开的受控浏览器。

## 已打开浏览器限制

普通未启用 remote debugging 的浏览器不能保证接管。需要接管已有 Chrome 时，指导用户关闭对应实例后使用类似参数重新启动：

```bash
chrome --remote-debugging-port=9222 --user-data-dir=<temporary-profile-dir>
```

然后使用当前 CLI 版本支持的连接命令连接，例如：

```bash
agent-browser connect 9222
```

具体参数以 `references/agent-browser-cli-reference.md` 和当前 `agent-browser --help` 输出为准。

## 敏感操作确认

连接已有登录态浏览器后默认只允许只读观察、截图和状态确认。以下操作必须二次确认范围：

- 表单提交、删除、支付、发布或生产系统写操作。
- 上传、下载、剪贴板或本地文件访问。
- 跨域导航、代理、授权头、持久 profile 或认证状态导入导出。
- 任何可能暴露用户账号、Cookie、Token 或私密页面内容的操作。

## 输出要求

执行后说明已选择的目标类型、用户确认依据、连接结果、只读或写操作边界，以及后续浏览器命令产生的证据路径。
