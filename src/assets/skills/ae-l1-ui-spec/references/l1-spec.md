# L1 步骤摘要

## 目标

用结构化文档精确描述所有图形界面，使任何人无需追问即可还原出功能等价的界面。

## 适用条件

系统有图形界面时执行此步骤。纯后端服务、命令行工具、嵌入式系统跳过本步，直接进入 L2。跳过不影响后续步骤的回退链路。

## 任务清单

| 任务 | 说明 |
|------|------|
| T1 列出所有视图 | 每个视图标注：归属模块/端、目标用户角色、进入条件 |
| T2 定义布局结构 | 区域类型（表单/列表/详情/导航/标签页/侧边栏）、位置、内容 |
| T3 定义数据绑定 | 绑定到 data-model 的实体.字段 或 contracts 的响应字段、显示格式、可编辑/只读 |
| T4 定义交互行为 | 触发条件、动作类型（导航/提交/校验/弹窗/刷新）、目标 |
| T5 定义状态相关显示 | 引用 state-machines 的状态，元素可见/隐藏/禁用/高亮 |
| T6 定义校验规则 | 引用 invariants 的不变量，字段级和联动校验 |
| T7 生成还原验证产物 | verification.html 或其他技术栈还原产物，验证完可丢弃 |
| T8 执行可还原性验证 | R = 0.4S + 0.4F + 0.2B，达标阈值 R ≥ 0.9 |

## 还原度维度

| 维度 | 权重 | 检查内容 |
|------|------|---------|
| 结构等价 S | 0.4 | 实体/字段/布局在还原产物中是否一一对应 |
| 功能等价 F | 0.4 | 操作/用例在还原产物中是否可触发且结果一致 |
| 行为边界 B | 0.2 | 前置条件违反、异常场景是否正确处理 |

## 验收关卡

| 编号 | 检查项 | 通过标准 |
|------|--------|---------|
| L1-K1 | 数据绑定可解析 | source 可解析到 data-model 或 contracts |
| L1-K2 | 交互目标可解析 | target 可解析到已有视图或外部动作 |
| L1-K3 | 状态引用存在 | 引用的 state-machines 状态存在 |
| L1-K4 | 不变量有 UI 约束 | 不变量在 UI 层有对应约束 |
| L1-K5 | 还原度达标 | R ≥ 0.9 |
| L1-K6 | 指纹一致 | upstream_fingerprints 与 G1-G3、A1-A2 产物一致 |
| L1-K7 | 文件行数合规 | 所有产物文件不超过 500 行 |

## 回退规则

- 数据绑定错误 → 回 G2
- 交互跨模块未定义契约 → 回 A1
- 纯 UI 描述不清 → 仅重做 L1

## 通用产物规格

- 单轨格式：YAML Frontmatter 为唯一真源，正文为人类阐释
- 文件行数硬约束：每个产物文件不超过 500 行
