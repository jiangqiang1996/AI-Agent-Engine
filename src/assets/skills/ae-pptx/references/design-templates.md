# PPTX 配色设计指南

不使用固定模板。每次生成前 AI 根据内容主题、受众和场景临时设计一套配色方案。本文件提供设计维度、约束和参考方案。

---

## 配色方案维度

设计配色方案时必须确定以下维度，全程统一遵循：

| 维度 | 说明 | 约束 |
|------|------|------|
| 主色 | 标题条/页脚/封面背景 | 深色，投影可读 |
| 强调色 | accent 竖条/装饰/链接 | 与主色对比度高 |
| 内容页背景 | 内容页底色 | 通常白色 |
| 封面/结束页背景 | 封面和结束页底色 | 通常等于主色 |
| 标题文字色（色条上） | 色条上的标题文字 | 白色或浅色 |
| 标题文字色（白底页） | 白底页大标题 | 深色，与主色同色系 |
| 正文文字色 | 内容页正文 | 深灰或黑色 |
| 辅助文字色 | 次要信息、页码、页脚 | 浅灰 |
| 卡片背景色 | 2-4 种浅色 | 用于卡片/色块 |
| 卡片色条色 | 2-4 种与卡片背景同色系深色 | 用于卡片左侧装饰条 |
| 侧栏色 | 封面/结束页左侧栏 | 主色的深色变体 |

---

## 设计约束

1. **主色 + 强调色不超过 2 个主色调** — 卡片色系可多色但需协调
2. **深色背景配浅色文字，浅色背景配深色文字** — 对比度足够投影可读
3. **颜色格式** — 6 位 HEX，不带 `#`（如 `16213E`）
4. **字号层级** — 至少定义 3 级：标题字号、正文字号、辅助字号
5. **字体** — 标题字体、正文字体、代码字体（Consolas）各一个
6. **用户优先** — 用户指定风格或品牌色时采纳用户指定

### 色彩校准（由 `@ui-designer` 定义（可通过 `mode=inline` 获取设计决策包））

- 最多 1 个强调色，默认饱和度 < 80%
- **LILA 规则：** 避免"AI 紫色/蓝色辉光"作为默认。使用中性基色（深灰/墨色/深蓝）配高对比单一强调色
- **色彩一致性锁定：** 一旦选择强调色，用于整个演示文稿所有页面
- **每个演示文稿一个调色板**，不混用暖灰和冷灰
- **无纯黑 `#000000` 和无纯白 `#FFFFFF`** — 使用近黑（如 `1A1A1A`）和近白（如 `FAFAFA`）。**例外**：深色背景上的文字色允许 `FFFFFF`（投影对比度优先），内容页背景允许 `FFFFFF`（Office 文档标准白底）
- 投影场景对比度要求：正文 WCAG AA 最低，标题文案 AAA 目标

### AI Tell 禁令（由 `@ui-designer` 定义（可通过 `mode=inline` 获取设计决策包））

以下模式在 PPTX 生成中**完全禁止**：

- 无 AI 紫色渐变作为默认配色
- 无过饱和强调色（如纯 `#FF00FF`、纯 `#00FFFF`）
- 无过度渐变文字填充
- 无"三张等宽功能卡片"作为唯一布局模式（可用但需有节奏变化）
- 无通用占位文字（如 "Lorem Ipsum"、"Acme Inc"、"Jane Doe"）
- 无装饰性假数据图表

### 风格变体参考（由 `@ui-designer` 定义（可通过 `mode=inline` 获取设计决策包））

根据内容主题选择一个风格方向并完全投入，不在同一演示文稿中混用：

| 风格变体 | 适用场景 | 关键特征 |
|---------|---------|---------|
| 极简编辑风 | 高端工具型产品、编辑博客、文档型演示 | 暖单色 + 点缀淡彩，大量留白，卡片细线边框，圆角 8-12pt |
| 工业粗野主义 | 数据密集仪表盘、技术架构展示 | Swiss 工业印刷或战术遥测风，绝对直角，无圆角 |
| 高端编辑奢侈风 | 生活方式、房地产、代理商 | 空灵玻璃感 / 柔和结构主义，夸张圆角，Double-Bezel 卡片 |
| 暗色科技风 | 开发者工具、安全产品、技术文档 | 等宽字体主导 + 单一霓虹强调色，终端窗口主题，网格背景 |

## 配色设计思路

### 设计读数推断（由 `@ui-designer` 定义（可通过 `mode=inline` 获取设计决策包））

在设计配色之前，先推断演示文稿的设计意图：

**读取信号：**
1. **演示类型** — 技术分享 / 产品介绍 / 商务汇报 / 学术报告 / 数据展示 / 党政报告
2. **受众** — 技术团队 / 管理层 / 学术同行 / 公众 / 党政干部
3. **氛围关键词** — "极简"、"科技感"、"严肃"、"活泼"、"高端"、"数据密集"
4. **投影环境** — 大屏会议室 / 小屏远程 / 打印分发
5. **已有品牌资产** — logo 配色、品牌字体、企业 VI

**设计读数声明：** 在设计配色前，用一句话声明：**"将此理解为：[演示类型] 面向 [受众]，采用 [氛围] 语言，倾向 [风格变体]。"**

**反默认纪律：** 不默认使用 AI 紫色渐变、深色背景居中标题三等宽卡片、到处通用毛玻璃。

### 视觉密度推断（由 `@ui-designer` 定义（可通过 `mode=inline` 获取设计决策包） VISUAL_DENSITY 旋钮）

| 信号 | 密度方向 | 布局影响 |
|------|---------|---------|
| 数据密集仪表盘 | 高密度 | 紧凑间距，小字号，1px 线条分隔 |
| 标准商务汇报 | 中密度 | 标准间距，中等字号 |
| 极简编辑风 | 低密度 | 大量留白，大字号，少元素 |

### 根据内容主题推断配色方向

| 内容主题 | 配色方向 | 参考主色范围 | 参考强调色范围 |
|---------|---------|-------------|--------------|
| 技术分享/产品介绍 | 深色背景 + 高对比强调色 | 深蓝/深灰/墨色 | 红/橙/青/绿 |
| 商务汇报/项目总结 | 白底 + 稳重主色 | 深蓝/灰蓝/墨绿 | 蓝/橙/金 |
| 学术/简约 | 白底 + 低饱和 | 深灰/黑 | 蓝/绿 |
| 数据展示/成果汇报 | 深色背景 + 多色统计 | 深蓝/深紫 | 红/橙/绿/蓝 |
| 党政类 | 红色主色 + 金色强调 | 深红 | 金/黄 |
| 科技/未来感 | 深色背景 + 霓虹色 | 深蓝/黑 | 青/亮蓝/薄荷绿 |

以上仅为推断参考，AI 应根据具体内容灵活设计，不限于上述方向。

## 字号层级参考

| 元素 | 字号范围 | 说明 |
|------|---------|------|
| 封面主标题 | 36-48pt | 加粗 |
| 封面副标题 | 18-24pt | 强调色 |
| 内容页标题（色条上） | 20-24pt | 加粗，白色 |
| 内容页标题（白底） | 26-32pt | 加粗，主色 |
| 正文 | 12-14pt | 正文文字色 |
| 辅助文字 | 10-11pt | 辅助文字色 |
| 大数字统计 | 28-40pt | 加粗，彩色 |
| 代码内容 | 10-12pt | Consolas |

### 排版指令（由 `@ui-designer` 定义（可通过 `mode=inline` 获取设计决策包））

- **标题默认：** 紧字距（tight tracking），行高 1.0-1.1，加粗
- **正文默认：** 正常字距，行高 1.4-1.6，最大行宽不超过 860pt
- **展示字体选择：** 优先 Calibri Light / Arial / 思源黑体 Light；避免 Inter 作为默认
- **正文字体选择：** Calibri / Arial / 思源黑体；与标题字体同族或协调
- **等宽字体：** Consolas / JetBrains Mono / Cascadia Code（用于代码块和数据）
- **衬线纪律：** 衬线字体仅当品牌明确指定或美学方向为编辑/奢侈/出版时才可使用
- **字号层级至少 3 级**：标题、正文、辅助，投影场景正文不小于 12pt

## 文本 shape 尺寸约束（硬约束）

每个文本 shape **必须显式设置 `w` 和 `h`**。不设置时使用 OOXML 默认占位符尺寸（约 283.46×141.73pt，通过 `view mode=html` 观察得出），会导致：

- **文字溢出**：长文本超出 283pt 宽度被截断
- **bounding box 重叠**：141.73pt 默认高度远大于单行文字，相邻文本框包围盒大量重叠

### 文本框尺寸估算

```
行数 = ceil(文本长度 / 每行字符数)
每行字符数 ≈ 文本框宽度(pt) / (字号(pt) × 0.55)  [ASCII]
每行字符数 ≈ 文本框宽度(pt) / 字号(pt)            [CJK]
文本框高度 = 行数 × 字号 × 1.4
```

### 常见文本框尺寸

| 用途 | 建议宽度 | 建议高度 |
|------|---------|---------|
| 单行标题 | 600-800pt | 字号 × 1.5 |
| 单行正文 | 600-860pt | 字号 × 1.5 |
| 多行正文 | 600-860pt | 行数 × 字号 × 1.4 |
| 统计数字 | 卡片宽度 | 字号 × 1.5 |
| 统计标签 | 卡片宽度 | 字号 × 1.5 |
| 代码行 | 800-880pt | 字号 × 1.4 |
