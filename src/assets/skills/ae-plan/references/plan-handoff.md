# 计划交接

本文件包含计划写入后的说明。在计划文件已写入且信心检查完成之后加载。

## 5.3.8 文档审查

在计划文件上运行 `ae:review mode:headless domain:document <plan-path>`。强制性的——即使信心检查已运行。

信心检查和文档审查捕获不同类别的问题：
- 信心检查加强理由、排序、风险处理
- 文档审查检查一致性、可行性、范围对齐

**管道模式：** 以 `mode:headless` 运行。无头模式静默应用自动修复并返回结构化发现。

## 5.3.9 最终检查和清理

确认计划在具体方面更强了、边界完好、源决策被保留。如果使用了制品暂存模式，清理临时目录。

## 5.4 生成后选项

**管道模式：** 跳过交互菜单，立即将控制权返回给调用者。

文档审查完成后，呈现选项：

**问题：** "计划已就绪。接下来你想做什么？"

**选项：**
1. **启动 `/ae-work`**（推荐）
2. **暂时完成**

**上下文中提供额外的文档审查：** 当有未解决的 P0/P1 发现时提议再跑一轮。

根据选择路由。如用户需要外部跟踪，输出计划路径和摘要即可。
