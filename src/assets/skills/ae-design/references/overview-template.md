# 设计总览维度契约模板

**触发条件：** 必产出
**产出位置：** `global.md` 的设计读数 + 契约版本 + 跨模块一致性约束章节
**产出方：** 主代理（ae:design 自身），不调度子代理
**可还原性目标：** 任意 AI 据此理解整体设计意图和模块间关系

## 契约元素（MVCE）

overview 维度的最小可验证契约元素集，标注 `[核心]` 或 `[可选]`：

- `[核心]` **设计读数**：一句话声明设计意图和美学家族
- `[核心]` **契约版本**：版本号、前序版本、变更摘要
- `[核心]` **跨模块一致性约束声明**：模块间必须遵守的一致性约束

> 全局架构（技术选型、ADR、模块清单与边界、跨模块依赖、数据流）产出到 `global.md` §全局架构，详见 `architecture-template.md`。
> 跨模块映射产出到 `global.md` §跨模块映射，详见 `cross-dimension-mapping.md`。

## 契约内容

```markdown
## 设计读数

（一句话声明设计意图和美学家族）

## 契约版本

- 版本号：1.0（初始）或递增
- 前序版本：无（初始）或前序版本号
- 变更摘要：本次变更概述

## 跨模块一致性约束

（声明模块间必须遵守的一致性约束，作为跨模块一致性的单一真源锚点）

| 约束 | 涉及模块 | 约束内容 | 验证方式 |
|------|---------|---------|---------|
| 认证传递 | auth, resource | resource 模块所有端点必须校验 auth 模块签发的 token | 集成测试 TC-INT-002 |
| 审计写入 | auth, resource, audit | 所有写操作必须同步写入 audit 模块的审计日志 | 集成测试 TC-INT-AUDIT-* |
| 数据级联 | auth, resource | 用户删除后资源级联删除 | ON DELETE CASCADE |
```

## 负向设计空间

- **禁止模块遗漏**：prd 映射的模块必须在 global.md §模块清单与边界中声明，不得缺失
- **禁止模糊约束**：跨模块一致性约束必须指明具体字段和约束类型，不得写"相关"或"对齐"等模糊表述
- **禁止稳定 ID 重用**：废弃的 ADR-XXX、EP-XXX、TC-XXX 等 ID 不得在新版本中重用

## 稳定 ID 体系

overview 中的设计条目必须使用稳定 ID，便于 ae:design / ae:work / ae:review 追溯：

- `ADR-XXX`：架构决策记录（全局，在 global.md 中）
- `EP-XXX`：API 端点编号（模块级，跨模块映射依赖）
- `T-XXX`：数据库表名编号（模块级，跨模块映射依赖）
- `TC-XXX`：测试用例编号（模块级，跨模块映射依赖）
- `ST-XXX`：UI 交互状态机编号（模块级，跨模块映射依赖）
- `COMP-XXX`：UI 组件编号（模块级，跨模块映射依赖）
- `PAGE-XXX`：页面编号（模块级，路由表依赖）

稳定 ID 在 design 文档全生命周期不变；版本演化时新增 ID，不重用已废弃 ID。
