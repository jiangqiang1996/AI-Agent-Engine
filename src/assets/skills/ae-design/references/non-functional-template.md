# 非功能设计维度契约模板

**触发条件：** prd 标注涉及性能/并发/事务/容量，或风险维度命中"性能敏感"（条件必产出）
**产出文件：** `non-functional/non-functional.md`（始终拆分为独立子文件，不内联，位于 non-functional 子目录中）
**产出方：** `@non-functional-designer` 子代理
**可还原性目标：** 任意 AI 据此实现满足非功能指标的代码

## 契约元素（MVCE）

non-functional 维度的最小可验证契约元素集，标注 `[核心]` 或 `[可选]`：

- `[核心]` **性能目标表**：指标、目标值、测量条件、量化方式、校验方式
- `[核心]` **并发模型与锁策略**：并发模型、锁策略、死锁预防
- `[核心]` **事务边界与隔离级别**：事务边界、隔离级别、超时策略
- `[可选]` **缓存策略表**：缓存层、存储内容、TTL、失效策略
- `[可选]` **容量规划**：初始容量、扩容触发、扩容方式
- `[核心]` **负向设计空间**：禁止的非功能模式

轻量级任务可省略 `[可选]` 元素。

## 契约内容

```markdown
## 非功能设计

### 性能目标

| 指标 | 目标值 | 测量条件 | 校验方式 |
|------|--------|---------|---------|
| 响应延迟 p50 | < 100ms | 正常负载 | 压测工具 + APM |
| 响应延迟 p99 | < 500ms | 正常负载 | 压测工具 + APM |
| 吞吐量 | 1000 req/s | 峰值 | 压测工具 |

### 并发模型与锁策略
- 并发模型：[线程池 / 事件循环 / Actor]
- 锁策略：[乐观锁 / 悲观锁 / 无锁]
- 死锁预防：[锁顺序 / 超时]

### 事务边界与隔离级别
- 事务边界：[操作范围]
- 隔离级别：[READ COMMITTED / REPEATABLE READ / SERIALIZABLE]
- 超时策略：[事务超时时间]

### 缓存策略

| 缓存层 | 存储内容 | TTL | 失效策略 |
|--------|---------|-----|---------|
| L1 (内存) | 热点数据 | 60s | LRU |
| L2 (Redis) | 会话数据 | 30min | TTL |

### 容量规划
- 初始容量：[QPS / 存储量 / 连接数]
- 扩容触发：[阈值]
- 扩容方式：[水平 / 垂直]

### 资源限制
- CPU 限制：[核数]
- 内存限制：[GB]
- 磁盘限制：[GB]
- 网络限制：[带宽]
```

## 负向设计空间

non-functional 维度的禁止模式：

- **禁止无量化指标**：性能目标必须量化（如 p99 < 500ms），不得写"高性能"或"快速响应"
- **禁止无校验方式的指标**：每个性能目标必须指明校验方式（压测工具、APM、日志统计等）
- **禁止无超时的事务**：所有事务必须配置超时时间，防止长事务阻塞连接池
- **禁止无失效策略的缓存**：缓存必须配置 TTL 或 LRU 等失效策略，不得无限增长
- **禁止无扩容预案的容量规划**：容量规划必须包含扩容触发阈值和扩容方式
