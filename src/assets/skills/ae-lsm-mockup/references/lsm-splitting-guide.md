# LSM 视觉还原产物拆分策略

视觉还原产物的核心实体是 `M-*` 还原映射，每条映射记录一个 UI 组件/页面与 HTML 原型的对应关系和还原程度。拆分时按页面或功能域分组，保证同一页面内所有还原映射的完整性。

## 行数限制

单个产物文件不得超过 800 行（含 frontmatter）。超过时必须拆分为文件夹结构。

## 拆分维度

按页面或功能域分组 `M-*` 条目。同一页面的所有还原映射放在同一子文件中，不跨页面拆分。

## 目录结构

```
ae/lsm/mockup/
└── <project-name>/
    ├── index.md               # 索引文件
    ├── dashboard.md           # 仪表盘页面的 M-* 条目
    ├── settings.md            # 设置页面的 M-* 条目
    └── ...
```

## 索引文件

索引文件 `index.md` 是文件夹的入口，必须包含：

1. **完整 frontmatter**：与未拆分产物相同的元数据，附加 `splitFrom`（原单文件名）和 `totalFiles`（子文件数量）
2. **视觉还原概述**：一段话描述整个还原的范围、还原策略和总体还原程度
3. **子文件索引表**：列出每个子文件的文件名、涵盖的 `M-*` ID 范围和作用描述

```markdown
---
lsmKind: mockup
upstreamRefs: [...]
traceTable: { ... }
trimmingGuide: { ... }
splittingGuide: { ... }
splitFrom: <project-name>.md
totalFiles: <N>
---

# LSM Mockup: [项目名称]

## 视觉还原概述

[一段话描述整个还原的范围、还原策略和总体还原程度]

## 子文件索引

| 文件名 | 范围 | 作用 |
|--------|------|------|
| dashboard.md | M-001 ~ M-003 | 仪表盘页面的视觉还原映射 |
| settings.md | M-04 ~ M-06 | 设置页面的视觉还原映射 |
```

## 子文件

每个子文件必须包含：

1. **轻量 frontmatter**：`lsmKind: mockup` 和 `parentIndex: ./index.md`
2. **该页面的完整还原映射**：设计映射、HTML 原型路径、还原程度

```markdown
---
lsmKind: mockup
parentIndex: ./index.md
---

# 仪表盘页面还原

## M-001: 导航栏还原

[完整还原映射内容]
```

**禁止拆断单个 `M-*` 条目**：每个还原映射的设计引用、原型路径和还原程度必须完整存在于同一子文件中。

**HTML 原型文件**：原型文件放在产物路径下，不受拆分影响。索引文件和子文件中的 HTML 原型路径统一使用相对于产物根目录的路径。

## 拆分触发

1. AI 生成产物时，先评估预估行数；若预计超过 800 行，直接按拆分结构生成
2. 生成过程中发现行数超限时，暂停并重构为拆分结构
3. 拆分时优先按页面边界分组，保持每个子文件内还原映射的逻辑完整性
