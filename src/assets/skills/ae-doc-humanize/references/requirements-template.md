# 自包含需求文档模板

用于把 `type: brainstorm` 的 AI 结构化需求产物转换为人读需求文档。

输出文档必须完整承载需求语义。允许记录上游文件路径用于溯源，但不得要求读者打开上游文件才能理解需求。

```markdown
---
type: requirements
date: YYYY-MM-DD
title: <kebab-case-title>
upstream: <上游文件路径>
---

# <人类可读标题>

## 文档说明

本文档描述 <主题> 的需求范围、功能要求、验收标准、约束和开放问题。上游文件：`<上游文件路径>`。本文档为自包含版本，不依赖打开上游文件即可阅读和评审。
```

## 转换要求

- 保留所有需求 ID（如 `R1`、`R2`）和非功能需求 ID（如 `NFR1`、`NFR2`）。
- 保留可恢复 `type: brainstorm` 正文结构所需的信息：问题框架、用户与场景、需求分组、成功标准、范围边界、关键决策、依赖/假设、待定问题、等价性计数和下一步。
- 必须记录上游文件路径，但不得用上游路径替代正文内容。
- 如果源文档有验收条件，必须移动到对应需求下或“验收标准”章节，不得省略。
- 可选章节只在源文档有对应语义时出现。
