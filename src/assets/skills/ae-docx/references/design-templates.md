# DOCX 风格设计指南

不使用固定模板。每次生成前 AI 根据内容主题、受众和场景临时设计一套风格方案。本文件提供设计维度、约束和参考方向。

---

## 风格方案维度

设计风格方案时必须确定以下维度，全程统一遵循：

| 维度 | 说明 | 约束 |
|------|------|------|
| 标题色 | 各级标题颜色 | 深色，与正文对比 |
| 正文色 | 正文文字颜色 | 深灰或黑色 |
| 强调色 | 强调/链接颜色 | 与标题色协调 |
| 表格表头底色 | 表头背景色 | 深色配白字或浅色配深字 |
| 表格表头文字色 | 表头文字颜色 | 与表头底色高对比 |
| 表格边框色 | 表格边框颜色 | 浅灰或中性色 |
| 标题字体 | 标题字体名称 | — |
| 正文字体 | 正文字体名称 | — |
| 一级标题字号 | Heading1 字号 | 16-20pt |
| 二级标题字号 | Heading2 字号 | 13-16pt |
| 正文字号 | 正文字号 | 10-12pt |
| 标题前间距 | 标题段前间距 | — |
| 标题后间距 | 标题段后间距 | — |
| 正文行间距 | 正文行距倍数 | 1.15x-2x |
| 首行缩进 | 正文首行缩进 | 0pt 或 0.74cm |
| 页眉文本 | 页眉内容 | — |
| 页脚文本 | 页脚内容 | — |
| 纸张尺寸 | 页面尺寸 | A4 或 Letter |
| 页边距 | 上下左右边距 | — |

## 设计约束

1. **所有颜色使用 6 位 HEX 格式**，不带 `#`（如 `2C3E50`）
2. **深色背景配浅色文字，浅色背景配深色文字**
3. **字号层级至少 2 级标题** — Heading1 和 Heading2
4. **用户优先** — 用户指定风格或品牌色时采纳

### 色彩校准（借鉴 ui-design-spec）

- 最多 1 个强调色，默认饱和度 < 80%
- **LILA 规则：** 避免"AI 紫色/蓝色辉光"作为默认。使用中性基色（深灰/墨色/深蓝）配高对比单一强调色
- **色彩一致性锁定：** 一旦选择强调色，用于整个文档所有章节
- **无纯黑 `#000000` 和无纯白 `#FFFFFF`** — 使用近黑（如 `1A1A1A`）和近白（如 `FAFAFA`）。**例外**：文档背景允许 `FFFFFF`（Office 文档标准白底）

### 排版指令（借鉴 ui-design-spec）

- **标题默认：** 紧字距，加粗，与正文有明显字号差
- **正文默认：** 行高 1.5-2x，最大行宽不超过页面可用宽度
- **字体选择：** 优先 Calibri / 思源黑体 / Arial；学术文档可用 Times New Roman；避免 Inter 作为默认
- **衬线纪律：** 衬线字体仅当品牌明确指定或美学方向为编辑/奢侈/出版/学术时才可使用

### AI Tell 禁令（借鉴 ui-design-spec）

- 无 AI 紫色渐变作为默认配色
- 无过饱和强调色
- 无通用占位文字
- 无装饰性假数据

## 风格设计思路

根据内容主题推断风格方向：

| 内容主题 | 配色方向 | 字体方向 | 间距方向 |
|---------|---------|---------|---------|
| 商务报告/项目文档 | 深蓝/灰蓝主色 + 蓝色强调 | Calibri 系无衬线 | 1.5x 行距，不缩进 |
| 学术论文/研究报告 | 深灰主色 + 蓝色强调 | Times New Roman 衬线 | 2x 双倍行距，首行缩进 |
| 简洁文档/备忘录 | 深灰主色 + 灰色强调 | Calibri 系无衬线 | 1.15x 行距，不缩进 |
| 技术文档 | 深蓝主色 + 青色强调 | Calibri 系无衬线 | 1.5x 行距，不缩进 |

以上仅为推断参考，AI 应根据具体内容灵活设计。
