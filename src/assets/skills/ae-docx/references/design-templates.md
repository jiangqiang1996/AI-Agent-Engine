# DOCX 设计模板

3 套内置设计模板，选定后全程遵循。

---

## 1. business-report — 商务报告 / 项目文档

| 维度 | 值 |
|------|-----|
| 标题色 | `2C3E50` |
| 正文色 | `555555` |
| 强调色 | `3498DB` |
| 表格表头底色 | `2C3E50` |
| 表格表头文字色 | `FFFFFF` |
| 表格边框色 | `BDC3C7` |
| 标题字体 | `Calibri Light` |
| 正文字体 | `Calibri` |
| 一级标题字号 | `18pt` |
| 二级标题字号 | `14pt` |
| 正文字号 | `11pt` |
| 标题前间距 | `18pt` |
| 标题后间距 | `6pt` |
| 正文行间距 | `1.5x` |
| 首行缩进 | `0pt`（商务报告不缩进） |
| 页眉文本 | 文档标题 |
| 页脚文本 | 页码 + 日期 |
| 纸张尺寸 | `A4` |
| 页边距 | 上下 2.54cm，左右 3.18cm |
