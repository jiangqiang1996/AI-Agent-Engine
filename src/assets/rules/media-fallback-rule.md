# 媒体识别自动降级规则

**本规则为全局硬约束，适用于任何会话、任何角色需要识别图片、音频或视频内容的场景。无例外。**

无论通过技能、代理、命令、工具还是 bash，当需要读取或理解媒体文件（图片/音频/视频）内容时，必须先判断当前模型是否支持对应的媒体类型输入；不支持时，必须通过 AE 媒体识别技能完成转换，不得直接用 Read 工具读取媒体文件。

## 核心规则

1. **图片识别降级** — 当需要识别图片内容，且当前模型不支持图像输入（vision）时，必须使用 `ae:image` 技能将图片转为 Markdown 描述。模型支持 vision 时可直接用 Read 工具读取图片。
2. **音频识别降级** — 当需要识别音频内容（语音转写、环境声音、音乐片段、情绪语气等），且当前模型不支持音频输入时，必须使用 `ae:audio` 技能将音频转为 Markdown 描述。模型支持音频输入时可直接用 Read 工具读取音频。
3. **视频识别降级** — 当需要识别视频内容（场景时间线、对话旁白、字幕文字、动作事件等），且当前模型不支持视频输入时，必须使用 `ae:video` 技能将视频转为 Markdown 描述。模型支持视频输入时可直接用 Read 工具读取视频。
4. **禁止尝试直接读取不支持的媒体** — Read 工具读取模型不支持的媒体文件时会报错（如 "this model does not support image input"）。此时不得重试 Read，必须改用对应媒体技能。
5. **媒体技能是唯一转换入口** — 上层技能和代理不应自行实现媒体转文字逻辑，必须调用 `ae:image`、`ae:audio`、`ae:video` 之一。

## 模型配置

三个媒体技能分别使用 `ae.jsonc` 中 `modelScenarios` 配置的专用模型：

| 技能 | 场景配置键 | 用途 |
|------|-----------|------|
| `ae:image` | `modelScenarios.vision` | 图片识别 |
| `ae:audio` | `modelScenarios.audio` | 音频识别 |
| `ae:video` | `modelScenarios.video` | 视频识别 |

未配置对应场景时，由 opencode 自行分配当前默认模型。建议为每个场景配置支持对应媒体类型输入的多模态模型。

## 触发条件

以下情况必须改用媒体技能：

- Read 工具读取媒体文件报错"model does not support ... input"时
- 用户明确要求"识别/转写/分析/提取"媒体文件内容，且当前模型不支持该媒体类型时
- 文档技能（ae:pptx、ae:docx、ae:pdf、ae:xlsx）的 to-image 操作生成 PNG 后，模型不支持 vision 时，必须通过 `ae:image` 识别

## 适用范围

本规则覆盖所有需要识别媒体内容的场景，包括但不限于：内置技能、工作流代理、命令、直接工具调用、子代理，以及未来新增的任何需要读取媒体内容的技能/代理/命令/工具。

## 降级路径

- 模型支持对应媒体类型 → 直接用 Read 工具读取
- 模型不支持对应媒体类型 → 调用 `ae:image` / `ae:audio` / `ae:video` 技能转换
- 媒体技能调用失败（如未配置可用模型、文件过大等）→ 返回友好提示，不得跳过降级
