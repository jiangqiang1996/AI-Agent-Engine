# 优化后提示词文件模板

产物路径：`ae/prompt-optimize/<slug>-<YYYYMMDD-HHMMSS>.md`

- `<slug>`：从优化后提示词提炼的短横线小写标识，2-5 个词，不超过 40 字符。取自任务对象或动作（如 `refactor-parser-module`）。无法提炼时用 `prompt`。
- `<YYYYMMDD-HHMMSS>`：文件生成时刻的本地时间，24 小时制紧凑格式。
- 同一天多次优化产生不同文件，不覆盖。

文件模板：

```markdown
---
type: prompt-optimize
slug: <slug>
created: <ISO-8601 时间戳>
mode: <auto|pause>
dimensions: clarity, context, structure, constraints, output-format, examples
---
```

写入规则：

1. 目录不存在时创建 `ae/prompt-optimize/`。
2. 写入内容必须与聊天中展示的最终优化结果完全一致，不允许两处版本不同。
3. "优化后的提示词"章节正文不得包含"这是优化后的提示词""优化结果如下"等元描述。
4. 附录仅供回溯，不影响"优化后的提示词"章节被直接复制使用。
5. 写入后回报文件路径。
