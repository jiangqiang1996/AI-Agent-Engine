# PDF 版式设计指南

本文件是 `ae-pdf` 技能的设计参考。生成 PDF 前先按内容主题、受众和场景确定一套风格方案，全程统一遵循；不要每页各写各的。

---

## 1. 风格方案维度

每次生成前必须确定以下维度并全程遵循：

| 维度 | 说明 | 约束 |
|------|------|------|
| 页面尺寸 | A4 / Letter / Legal | 默认 A4 |
| 页边距 | 上下左右留白 | 48-72pt |
| 标题色 | 各级标题颜色 | 深色，与正文对比 |
| 正文色 | 正文文字颜色 | 深灰或黑色 |
| 强调色 | 强调/链接颜色 | 与标题色协调，全文只用 1 个 |
| 表头底色 | 表头背景色 | 深色配白字，或浅色配深字 |
| 表格线色 | 表格边框颜色 | 浅灰或中性色 |
| 标题字体/字号 | 标题字体与字号层级 | 至少 2 级标题 |
| 正文字体/字号 | 正文字体与字号 | 10-12pt |
| 行距 | 段前/段后与行高 | 行高 1.4-1.6 倍 |
| 页眉页脚 | 页眉/页脚内容 | 页码必须放在页脚 |
| 水印 | 是否加水印及样式 | 需用户明确要求时才加 |

---

## 2. 硬性约束

1. **颜色分量一律 0-1**：红色 `{r:1,g:0,b:0}`，不是 `{r:255,g:0,b:0}`。脚本虽会兜底归一化，但不要依赖。
2. **坐标单位是 pt**：1pt ≈ 1/72 inch ≈ 0.35mm；A4 = 595.28 × 841.89pt。
3. **y 轴原点在页面底部**：从顶部往下写，y 依次取 `pageHeight - 50`、`pageHeight - 90`……
4. **页码索引 0-based**：`--page-index 0` 就是第 1 页。
5. **不含 CJK 的文本不要指定 CJK 字体**；脚本会自动检测并切换，手工指定反而可能引入字体缺失问题。
6. **正文字号不低于 9pt**：低于 9pt 在打印件上基本不可读。

## 3. 典型结构模板

### 3.1 封面页

```
- 顶部留白 120pt
- 标题（24-32pt，粗体，标题色）
- 副标题（14-16pt，正文色）
- 分隔线（1pt，强调色，宽度 120pt）
- 元信息块（10-12pt，正文色，逐行排列）
```

### 3.2 内容页

```
- 页眉：文档名（左）+ 章节名（右），9pt，灰色
- 一级标题：18pt，粗体，标题色
- 二级标题：14pt，粗体，正文色
- 正文：11pt，行高 1.5 倍，段后间距 8pt
- 页脚：页码（居中，9pt，灰色）
```

### 3.3 表格页

```
- 表头行：表头底色 + 白字（或浅底 + 深字），加粗
- 数据行：斑马纹（每两行一层极浅底色），行高 1.3 倍
- 列宽按内容重要性分配：首列最宽，数字列右对齐
- 表格总宽度不超过版心宽度（A4 建议 ≤ 495pt）
```

### 3.4 图示/流程页

```
- 标题在上
- 图形区用 rect/ellipse/line 组合绘制
- 形状之间保持 ≥ 24pt 间距
- 图形下方配一行说明文字（10pt）
```

## 4. 色彩方向参考

| 内容主题 | 配色方向 | 字体方向 |
|---------|---------|---------|
| 商务报告 | 深蓝/灰蓝主色 + 单一强调色 | Helvetica 系无衬线 |
| 学术论文 | 深灰主色 + 克制强调色 | TimesRoman 系衬线 |
| 技术文档 | 深蓝主色 + 青色强调 | Helvetica 系无衬线 |
| 合同/表单 | 黑白灰，无强调色 | Helvetica 系无衬线 |

以上仅为推断参考，应根据实际内容灵活设计。

## 5. 常见排版错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 文字 y 坐标按 Web 习惯从 0 开始 | 文字跑到页面底部外 | 从 `pageHeight - 50` 往下排 |
| 多个文本元素都不给 y | 文字重叠成一坨 | 依赖自动排布，或逐个显式给 y |
| 表格宽度超过版心 | 内容被裁切 | 合计列宽 ≤ 版心宽度 |
| 中文用 Helvetica | 变成方框或空白 | 让脚本自动切 CJK 字体，或显式指定 |
| 字号 6-8pt | 打印不可读 | 正文 ≥ 10pt，脚注 ≥ 9pt |
