# 媒体降级策略（Media Fallback Policy）

> 用法：把本文件正文粘贴到项目根目录的 `AGENTS.md` / `CLAUDE.md`（或宿主的等价项目指令文件）中，让整个会话遵守同一条媒体处理规则。
> 本文件不依赖任何特定宿主，可直接复制使用。

## 背景

部分模型不支持直接读取图片、音频、视频输入。直接去读这些文件只会得到一条"该模型不支持此类输入"的错误，浪费一轮工具调用，却拿不到任何信息。

正确做法是：**先把媒体转成文字，再基于文字继续工作。**

## 规则

1. **先判断能力，再决定动作。** 确认当前模型支持该媒体类型时，直接读取；不支持时，转成文字后再读。
2. **不支持输入时，禁止直接读取媒体文件。** 不要用文件读取能力打开图片 / 音频 / 视频，不要反复重试同一次失败。
3. **降级要自动。** 不要询问"要不要识别这个文件"，也不要列出一堆方案让用户挑选——直接转换，拿到结果后继续原任务。
4. **最多重试一次。** 第一次失败时改用下一级后端（远程接口 → 本地命令 → 元信息兜底）；仍然失败就如实说明"无法解析该媒体"，并给出可执行的下一步（安装本地工具、配置接口、提供纯文本版本）。
5. **不编造。** 兜底输出只能包含可确定的客观信息（文件名、类型、大小、时长、编码）。画面内容、语音内容一律不得猜测。
6. **保留原始措辞。** 转写结果里的术语、命令、报错信息、代码原样保留，不改写、不总结成"大概意思"。

## 媒体类型与处理方式

| 媒体类型 | 转换方式 | 典型产物目录 |
|---------|---------|-------------|
| 图片（PNG / JPG / GIF / WebP / BMP） | 视觉接口描述，或本地 OCR 提取文字 | `ae/image/` |
| 音频（MP3 / WAV / M4A / FLAC / OGG） | 转写接口，或本地语音识别 | `ae/audio/` |
| 视频（MP4 / MOV / MKV / WebM / AVI） | 抽取关键帧逐帧描述 + 抽取音轨转写 | `ae/video/` |

对应的转换技能：`ae-image`（图片）、`ae-audio`（音频）、`ae-video`（视频）。只安装了其中一个时，用已安装的那个处理对应类型；其余类型按上面的规则如实说明即可。

## 典型场景

- **文档转图片后的视觉校验**：渲染出的 PNG 无法被模型直接查看时，先转文字，再核对排版、溢出、乱码、缺字。
- **界面截图分析**：把按钮、输入框、报错提示转成文字后，再做交互流程分析。
- **会议录音 / 教程视频**：转写为文字后，再做摘要、议题梳理、步骤提取。
- **用户直接贴了媒体路径**：先确认文件真实存在，再执行转换。

## 反面示例

- ❌ 模型不支持图片输入时，直接用文件读取能力打开 PNG。
- ❌ 转换失败后连续重试三次，或者换个方式再试三次。
- ❌ 接口没配好时，凭文件名作出一番"图片里是一张柱状图"之类的描述。
- ❌ 每处理一个文件都先问用户"要不要我识别一下"。
