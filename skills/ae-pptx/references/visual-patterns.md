# PPTX 内容可视化模式

将大纲内容类型映射为视觉元素，禁止用空格对齐模拟表格。

> **颜色说明**：以下示例中的 HEX 色值仅供布局模式参考。实际生成时必须使用本次临时设计的配色方案中的对应颜色值，将示例中的色值替换为配色方案维度（主色、强调色、卡片背景色、卡片色条色等）。
>
> **单位说明**：示例坐标一律按 pt 给出，**传给 `officecli` 时必须补 `pt` 后缀**（`x=50pt`）；
> 裸数字会被当成 EMU（`x=50` → 0.004pt，元素等于没画）。

---

## 0. 先选图，再写字

**能用图形承载的信息，不要写成句子。** 先判断"这页的信息是什么形状"，再决定画什么。

| 信息形状 | 首选图形 | 不要写成 |
|---------|---------|---------|
| 有先后关系 | 流程图（节点 + 箭头） | "第一步…第二步…第三步…" |
| 有包含关系 | 树状图 / 缩进层级 | 逐条罗列路径 |
| 有数量对比 | 条形图 / 大数字块 | "共 10 个，其中 4 个是…" |
| 有占比 | 环形图 / 百分比条 | "大约四成是…" |
| 有层级关系 | 金字塔 / 阶梯 | "上层是…下层是…" |
| 有枚举清单 | 编号步骤条 / 勾选格 | 逐条 bullet |
| 有对照关系 | 双列对比 | "A 是…，B 是…" |
| 只有一句话 | 一行标题 + 一个视觉锚点 | 三段说明 |

### 改造前后对照

| 原文案（文字多、看不出结构） | 改造后（图形承载） |
|---------------------------|------------------|
| 「持久产物 ae/<slug>/，临时产物 ae/<slug>/tmp/，日志 ae/logs/<slug>/」 | 目录树：3 层缩进 + 路径标签 |
| 「提交前要跑 sync、validate、test、check 四步」 | 横向流程条：4 个节点 + 箭头，命令写在节点下 |
| 「测试分四层，单元最快，端到端最全」 | 金字塔：4 层，层宽表达量级，层内写职责 |
| 「一共有 10 个技能，分 6 组，测试类最多」 | 条形图 + 2 个大数字块 |

> 改造的判据：**遮住图形后，读者应该还能靠剩下的文字读懂这页**；
> 如果遮住图形后什么信息都不剩，说明图形只是装饰，文字才是主体——那就该反过来：用图承载主体信息。

## 1. 彩色卡片色块 — 表格内容

**问题**：大纲中的表格直接用空格对齐，列对齐丢失，视觉混乱。

**做法**：每行一个彩色色块卡片，左侧色条 + 标题加粗 + 说明灰色。

**示例**：

```
卡片背景: fill=F0F4FF, x=50pt, y=75pt, w=860pt, h=55pt
左侧色条: fill=4472C4, x=50pt, y=75pt, w=5pt, h=55pt
标题: x=65pt, y=80pt, w=250pt, h=25pt, size=13pt, bold, color=4472C4
说明: x=320pt, y=83pt, w=580pt, h=20pt, size=11pt, color=555555
```

多行卡片依次向下排列，y 递增 65pt（卡片高 55pt + 间距 10pt），交替使用不同色系。

---

## 2. 编号步骤网格 — 工作流/流程

**问题**：编号列表平铺，缺乏视觉层次。

**做法**：每步一个彩色卡片，2-3 列网格，不同颜色，含步骤标题+描述。

**示例（2行3列）**：

```
卡片宽=270pt, 高=65pt, 间距=15pt
行1 y=75pt:  x=40pt, 345pt, 650pt
行2 y=160pt: x=40pt, 345pt, 650pt

每卡片:
  色块背景: fill=对应色浅色版
  标题: x=卡片x+15, y=卡片y+7, w=卡片宽-30, h=22pt, size=14pt, bold, color=对应色
  描述: x=卡片x+15, y=卡片y+30, w=卡片宽-30, h=30pt, size=11pt, color=555555
```

颜色循环：从配色方案的卡片色条色中依次取色，取尽后循环回第一种

## 3. 深色代码块 — 代码/配置

**问题**：代码用普通文本，无语法高亮，难以阅读。

**做法**：深色背景代码区 + Consolas 字体 + 关键词彩色。

**示例**：

```
代码块背景: fill=16213E, x=40pt, y=210pt, w=880pt, h=160pt
代码标题: x=60pt, y=220pt, w=840pt, h=22pt, size=14pt, bold, color=E94560
代码内容: x=60pt, y=245pt, w=840pt, h=115pt, font=Consolas, size=11pt
  关键词(quick/standard/deep/vision): color=对应色
  字符串: color=70AD47
  注释/标点: color=AAAAAA
```

---

## 4. 大数字统计块 — 数据/资产快照

**问题**：数字埋在文本中，不突出。

**做法**：大字号数字居中彩色卡片 + 标签下方。

**示例（4列大卡片 + 2列小卡片）**：

```
大卡片: w=200pt, h=120pt, 间距=20pt
  x: 50pt, 270pt, 490pt, 710pt
  y: 80pt
  数字: 居中, w=200pt, h=40pt, size=36pt, bold, color=FFFFFF
  标签: 居中, w=200pt, h=25pt, y=卡片y+65, size=13pt, color=浅色

小卡片: w=410pt, h=80pt, 间距=20pt
  x: 50pt, 500pt
  y: 220pt
  数字: 居中, w=410pt, h=35pt, size=28pt, bold, color=FFFFFF
  标签: 居中, w=410pt, h=25pt, y=卡片y+35, size=13pt, color=浅色
```

---

## 5. 双列对比 — 命令/映射表

**问题**：命令列表单列排列，浪费空间。

**做法**：左列命令（Consolas 蓝色）+ 右列说明（灰色），双列布局。

**示例**：

```
左列 x=60pt, w=180pt, h=25pt, font=Consolas, size=13pt, color=4472C4
右列 x=250pt, w=200pt, h=25pt, font=Calibri, size=12pt, color=555555
行高=30pt, 起始 y=80pt

右列第二组:
左列 x=520pt, w=180pt, h=25pt, color=ED7D31
右列 x=710pt, w=200pt, h=25pt
```

## 6. 树状结构 + 侧边流程图 — 架构/目录

**问题**：树状结构纯文本，缺少依赖方向可视化。

**做法**：左侧代码块（目录树）+ 右侧依赖方向流程图卡片。

**示例**：

```
左侧代码块:
  背景: fill=F8F9FA, x=40pt, y=70pt, w=450pt, h=250pt
  内容: x=55pt, y=80pt, w=420pt, h=230pt, font=Consolas, size=12pt, color=333333

右侧依赖方向卡片:
  背景: fill=F0F4FF, x=520pt, y=70pt, w=400pt, h=120pt
  色条: fill=4472C4, x=520pt, y=70pt, w=5pt, h=120pt
  标题: x=535pt, y=78pt, w=375pt, h=22pt, size=14pt, bold, color=4472C4
  流程:
    层名: w=375pt, h=20pt, font=Consolas, size=12pt
    箭头: w=375pt, h=20pt, size=14pt, color=4472C4, align=center

右侧约束卡片:
  背景: fill=FFF4E6, x=520pt, y=210pt, w=400pt, h=110pt
  色条: fill=ED7D31
  标题+列表: w=375pt, h=适当高度
```

## 文字密度控制（硬约束）

**每张幻灯片都不能全是文字。** 文字是配角，视觉元素才是主角。

| 指标 | 上限 | 超限处理 |
|------|------|---------|
| 单页**内容**行数（不含页眉标题/页码/页脚） | ≤ **10 行** | 拆页，或把段落改成图形 |
| 单个文本 shape 段落数 | ≤ **3 段** | 拆成多个 shape，或换成图形 |
| 卡片说明文字 | ≤ **20 字** | 删形容词，保留事实与数字 |
| 单页视觉元素数（纯装饰形状） | ≥ **1 个** | 必须补（卡片/图表/配图/大数字/代码块） |
| 文本形状面积 / 内容区面积 | ≤ **40%** | 该用图的地方用了字，改成图形承载 |
| 连续无视觉元素的页 | 不得连续 2 页 | 拆分或加配图 |

> 页眉标题、页码、页脚文字是**页面框架**，不计入内容行数，但会占掉 3 行版面空间。

### 文字量参考

| 元素 | 建议字数 |
|------|---------|
| 页面主标题 | ≤ 20 字（写事实，不写口号） |
| 副标题 | ≤ 30 字（写具体信息） |
| 卡片标题 | ≤ 12 字 |
| 卡片说明 | ≤ 20 字 |
| 图注 | ≤ 30 字 |
| 要点条目 | ≤ 50 字/条，条目 ≤ 5 条 |

> "文字适当"≠"文字越少越好"：每页该有的信息要给足，只是**用视觉结构承载**，
> 而不是堆成连续段落。判断标准是——遮住所有非文本元素后，这页应该还能被读懂。

### 文字改造路径

原文案太密时，按优先级依次改造：

1. **有数字 → SVG 图表**（见 [配图生成指南](illustrations.md)）
2. **有并列关系 → 彩色卡片网格**
3. **有先后关系 → 编号步骤卡片 / 流程图**
4. **有对比关系 → 双列对比 / 图表**
5. **有包含关系 → 树状图**
6. **实在装不下 → 拆页**

## 禁止事项

- 禁止用空格对齐模拟表格列
- 禁止纯文本堆叠不加任何视觉元素
- 禁止出现"纯文字页"（整页只有标题+段落）
- 禁止单页文字超过 14 行或单个文本块超过 3 行
- 禁止内容挤在顶部、底部大片留白
- 禁止文本框高度小于内容实际需要（导致溢出）
- 禁止文本 shape 不设置 w 和 h（会使用默认占位符尺寸约 283.46×141.73pt，通过 `view html` 观察得出，导致溢出和重叠）
- 禁止混用不同配色方案的配色
