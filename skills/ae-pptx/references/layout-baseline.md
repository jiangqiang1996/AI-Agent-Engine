# PPTX 布局基准

## 幻灯片尺寸

```
widescreen 16:9: 960pt × 540pt
单位换算: 1cm ≈ 28.35pt
```

## ⚠️ 单位约定（坐标必须显式带单位）

`officecli` 把**不带单位的数字当作原始 EMU**（1pt = 12700 EMU）：
`x=120` 得到的是 0.01pt 的元素——几乎看不见，页面会"什么都没有"。

| 写法 | 含义 | 结果 |
|------|------|------|
| `x=120` | 120 **EMU** | ❌ 0.01pt，等于没画 |
| `x=120pt` | 120 pt | ✅ |
| `x=4.23cm` | 4.23 cm | ✅ |
| `x=1in` | 1 英寸 | ✅ |

**本文件所有坐标都按 pt 给出，落到命令行时必须补上 `pt` 后缀**（如 `--prop x=120pt`）。
字号 `--prop size=28` 是唯一允许裸数字的字段（裸数字即 pt）。

## 坐标系

- 原点 (0,0) 在左上角
- x 轴向右递增，y 轴向下递增
- 本文件统一用 pt 标注坐标，传给 `officecli` 时加 `pt` 后缀

## 间距规则

| 间距类型 | 值 |
|---------|---|
| 页面左右边距 | 50pt |
| 标题区高度 | 50pt |
| 内容区顶部间距 | 20pt（色条下方） |
| 元素间垂直间距 | 15-25pt |
| 卡片间间距 | 20pt |
| 页脚区高度 | 30pt |
| 文本行高 | size × 1.4（约值） |

## 坐标计算公式

### n 个卡片等分宽度

```
可用宽度 = 960pt - 2 × 50pt = 860pt
卡片间距 = 20pt
卡片宽度 = (可用宽度 - (n-1) × 卡片间距) / n
卡片 x[i] = 50pt + i × (卡片宽度 + 卡片间距)
```

示例（4 个卡片）：

```
卡片宽度 = (860 - 3 × 20) / 4 = 200pt
x[0] = 50pt, x[1] = 270pt, x[2] = 490pt, x[3] = 710pt
```

### 文本框高度估算

```
行数 = ceil(文本长度 / 每行字符数)
每行字符数 ≈ 文本框宽度(pt) / (字号(pt) × 0.55)
文本框高度 = 行数 × 字号 × 1.4
```

### 卡片内文本位置

```
卡片标题: x = 卡片x + 15pt, y = 卡片y + 8pt
卡片正文: x = 卡片x + 15pt, y = 卡片y + 30pt
卡片色条: x = 卡片x, y = 卡片y, w = 5pt, h = 卡片高度
```
