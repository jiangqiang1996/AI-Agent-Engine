# 逐页字段核对纪律（prototype discipline）

此内容在 ui-ux / pages 维度契约产出后、进入 review 闭环之前加载；也适用于任何"从页面文档生成页面产物"（如原型 HTML 验证）的场景。

---

页面产物（`modules/<NN>-<m>/pages/*.md`，以及据其生成的原型 HTML）与页面文档真源之间必须执行**强制逐页字段核对**。本纪律为硬约束，任何参数或模式均不可跳过；核对通过后才可进入后续验收或 review 闭环。

## 1. 构建审查清单

从页面文档真源（ae-prd 原型的 `pages/<NN>-<page-name>.md` 字段清单；对设计页面产物则是 prd 原型页面文件）中提取完整字段清单，覆盖所有页面层级：

- **主页面字段**：每个页面的字段清单（字段名称、label 文本、类型、必填、验证规则、所属区域、选项列表）
- **子页面字段**：标签页内容、步骤内容、折叠面板内容、抽屉内容、下拉菜单面板、Popover/Tooltip 悬浮卡片、表格可展开行嵌套内容、侧边栏嵌套面板等嵌套区域中的字段清单
- **弹窗/对话框字段**：模态框、确认框、提示框、表单弹窗、通知/Toast 消息、下拉选择弹窗、全屏遮罩弹窗、嵌套弹窗等弹层中的字段清单，包括弹窗标题、正文、按钮

将文档中所有字段清单汇总为审查清单，每个条目记录：页面/子页面/弹窗标识、字段名称、期望 label 文本、期望类型、期望必填、期望验证规则、期望选项列表。

## 2. 逐页面审查

对每个页面产物逐一核对，审查项按优先级分级：

**P0 审查项（必须通过）：**

| 审查项 | 核对内容 |
|--------|----------|
| 表单字段 label 文本 | 产物中 label/占位文本与文档完全一致 |
| 字段类型 | input type、select、textarea、checkbox、radio 等与文档一致 |
| 必填标记 | required 标记与文档必填声明一致 |
| 验证规则 | 验证属性或验证逻辑与文档验证规则一致 |
| 选项列表 | select/checkbox/radio 的选项文本和数量与文档一致 |
| 页面/区域标题 | h1-h6、section 标题文本与文档一致 |
| 按钮文本 | button、submit 的文本与文档一致 |
| 链接文本与跳转目标 | 链接文本与跳转目标与文档一致 |
| 表格列头 | th 文本与文档一致 |
| 列表/菜单项文本 | li、菜单项文本与文档一致 |
| 面包屑文本 | 面包屑各层级文本与文档一致 |
| 图标辅助文本 | img alt、aria-label 文本与文档一致 |
| 徽标/状态标签 | badge、状态标签文本与文档一致 |
| 提示/帮助文本 | tooltip、帮助说明文本与文档一致 |
| 弹窗中的字段 | 逐弹窗核对，同上所有规则 |
| 弹窗标题与触发 | 弹窗标题文本与文档一致，触发条件与文档一致 |
| 业务闭环 | 每个业务流程从入口到结果反馈完整，无断头路 |
| 交互完整 | 每个功能点的成功、失败、边界情况交互路径均有定义 |

**P1 审查项（应通过）：**

| 审查项 | 核对内容 |
|--------|----------|
| placeholder/默认值 | 如文档有声明则一致 |
| 字段排列顺序 | 与文档字段清单顺序一致 |
| 字段所属区域 | 字段位于文档声明的布局区域内 |
| 弹窗关闭方式 | 与文档声明的交互一致 |
| 响应式行为 | 与文档响应式声明一致 |

**审查方法：** 读取每个页面产物文件的源码文本，提取所有表单控件、标题、按钮、链接、表格列头、列表项等元素的文本和属性，与审查清单逐项比对。不依赖浏览器渲染，纯源码文本核对。对于由 JS 动态生成的内容（如 createElement 构建的弹窗），同时提取 JS 代码中的字符串字面量和 createElement 调用参数作为补充审查源，确保动态生成的字段文本也被覆盖。

## 3. 修复不一致项

发现差异时，对照页面文档真源修正页面产物：

- **仅修正与文档不一致的部分**，不优化文档未提及的内容
- 修正后重新核对已修正项，确认修复生效
- 修复遵循产出阶段的所有硬约束（技术栈隔离、组件复用、禁止镀金等）

## 4. 审查循环与通过判定

- 最多 3 轮审查-修复循环
- 每轮审查覆盖所有页面、子页面、弹窗
- 3 轮后仍有 P0 审查项未通过时，标注未解决的 P0 项为残余风险，并询问用户是否继续
- 所有 P0 审查项通过后，方可进入后续验收（如浏览器验证，经 omp browser prelude）或 review 闭环

## 5. 核对结果记录

核对结束时记录：审查覆盖（N 个页面、M 个子页面、K 个弹窗）、P0/P1 审查项通过情况、修复轮次、剩余风险（未解决的 P0 项、文档描述模糊导致核对不确定的部分）。
